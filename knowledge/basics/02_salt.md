---
id: salt
title: 塩分の計算
---

レシピの `salt.total_g` は、使う調味料の塩分（食塩相当量）の合計。目安の表（`data/ingredients.yml` の `salt_per_*` と同じ値）:

| 調味料 | 量 | 塩分 g |
|---|---|---|
| 塩 | 小さじ 1（6g） | 6.0 |
| 醤油 | 大さじ 1（18g） | 2.6 |
| 味噌 | 大さじ 1（18g） | 2.2 |
| めんつゆ（3 倍濃縮） | 大さじ 1 | 1.5 |
| ポン酢 | 大さじ 1 | 1.3 |
| オイスターソース | 大さじ 1 | 1.8 |
| 焼肉のたれ | 大さじ 1 | 1.2 |
| 中濃ソース | 大さじ 1 | 1.0 |
| ケチャップ | 大さじ 1 | 0.5 |
| マヨネーズ | 大さじ 1 | 0.3 |
| 鶏がらスープの素 | 小さじ 1 | 1.2 |
| コンソメ | 1 個 | 2.5 |
| バター | 10g | 0.15 |
| 酒 | 大さじ 1 | 0.3 |
| みりん・砂糖・酢・油 | — | 0 |
| 塩鮭 1 切れ | 80g | 1.5 |
| ベーコン 1 枚 | 18g | 0.4 |
| ウインナー 1 本 | 20g | 0.4 |
| かまぼこ 2 切れ | 20g | 0.5 |

- 大人 1 人分 = total_g ÷ 大人の人数（子どもの分を先に取り分けるなら、取り分け後に入れた調味料だけで計算）。
- 子どもの分は `knowledge/safety.md` §3 の上限以下。1-2y なら 1 食 1.0g。取り分け後にタレを付けないのが一番簡単。
- `salt: light` の家では、レシピの醤油・味噌を 2〜3 割減らし、酸味（酢・ポン酢・レモン）、だし、香り（ごま油・しょうが・ねぎ）で補う。
