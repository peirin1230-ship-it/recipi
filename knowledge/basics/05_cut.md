title: 切り方と大きさ
---

| 名前 | 大きさの目安 | 向く物 |
|---|---|---|
| 一口大 | 3cm 角 | 鶏もも・豚ロース・じゃがいも |
| 小口切り | 5mm 厚 | 小ねぎ・きゅうり |
| 薄切り | 2〜3mm | 玉ねぎ・にんじん（炒め物） |
| 細切り | 3mm × 5cm | にんじん・ピーマン（きんぴら・炒め物） |
| 短冊切り | 1cm × 4cm × 2mm | 大根・にんじん（汁物） |
| いちょう切り | 5mm 厚の 1/4 | 大根・にんじん（味噌汁・煮物） |
| 乱切り | 3cm | にんじん・じゃがいも（煮物） |
| ざく切り | 4cm | 葉物・キャベツ |
| みじん切り | 2〜3mm | 玉ねぎ・にんにく・しょうが |

- 火の通りをそろえるため、同じ料理の中では同じ大きさに。
- 根菜は薄く・小さく切るほど早く火が通る。時間予算が短いときは薄切り・細切りを選ぶ。
- 子どもの分は `knowledge/safety.md` §2 の大きさ。
