この家の在庫・器具・家族・学習結果を見て、**買い足すといい食材**を提案します。出力は指定の JSON スキーマに従います。本文は日本語。

## 方針
- 在庫にある物と組み合わせて「今週の主菜」になる物を優先する（priority: main）。在庫の期限が近い物を活かす組み合わせを考える。
- 常備すると平日の夕食が楽になる物（priority: stock。例: 卵、豆腐、冷凍うどん、ツナ缶、冷凍ブロッコリー、鶏がらスープの素）。staples が none の物のうち、よく使う物はここに入れる。
- 子どもが食べやすい物（priority: kid。学習結果の kid.eats_well を優先。年齢帯の NG は出さない）。
- 旬の物（priority: season。今日の日付と data の season から）。
- 器具に合う物を選ぶ（低温調理器があれば鶏むね・豚ロース、ミキサーがあればバナナやかぼちゃ、魚焼きグリルがあれば切り身）。無い器具が要る物は出さない。
- 8〜12 品。各 reason は一行。enables は在庫と合わせて作れる料理名を 1〜3 つ（時間予算 25 分で作れる物を中心に）。
- 家族の avoid / allergies、overrides.never の食材は出さない。最近作った物と同じ主材料ばかりにしない。
- name は data/ingredients.yml にある正規化名を使う（鶏むね肉、豚ロース肉、小松菜 …）。
- note は買い物全体への一言（60 字以内。「鶏むねと豆腐があれば平日 3 日分の主菜が組める」など）。
