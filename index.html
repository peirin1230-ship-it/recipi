recipi 今夜の一皿
リポジトリ kaji-quest 仕様書
0 分

設定

記録・在庫・注文を書き込むには GitHub のトークンが要る（初回だけ）。
Fine-grained token を作る → Repository access: Only select repositories → recipi（kaji-quest にも書くなら両方）／ Permissions: Contents → Read and write

トークンはこの端末のブラウザにだけ保存され、GitHub API 以外には送らない。

  1. 「今夜」で時間を選んで「考えてもらう」。1〜2 分で「レシピ」に出る（閉じても大丈夫）。
  2. 「作る」で調理モード。タイマーと「できた」を押しながら進める。
  3. 最後の「できた！」で記録へ。写真 1 枚と星をつけて「記録する」。60 秒で終わる。
  4. 在庫は「、」区切りの入力か冷蔵庫の写真 1 枚。kaji-quest の買い物記録も取り込める。
